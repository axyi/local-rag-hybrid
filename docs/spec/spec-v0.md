# local-rag-hybrid — implementation spec v0

Upgrade the upstream `local-rag-mcp` RAG assistant with **LLM query expansion**,
**parallel BM25 full-text search** and **Reciprocal Rank Fusion**, plus a
vector-only vs hybrid retrieval benchmark. This document is the complete
contract: everything needed to implement, test and accept the work is inside it.

Every numbered requirement is tagged `MUST` or `NON-GOAL`. `MUST` items are
mandatory. Anything not stated here is out of scope.

All code fences demonstrating third-party APIs were executed against the pinned
versions on 2026-08-30 (disposable venv) — treat them as the authoritative API
reference, not as suggestions.

- **REQ-22 (MUST)** Module constants, verbatim:

- **REQ-23 (MUST)** One public function:
  `expand_query(question: str) -> list[str]`. It POSTs to `OLLAMA_URL` with
  `requests.post(OLLAMA_URL, json=payload, timeout=KEYWORD_TIMEOUT)` where
  `payload` is exactly:

  ```python
  {
      "model": OLLAMA_MODEL,
      "prompt": KEYWORD_PROMPT.format(question=question),
      "stream": False,
      "think": False,
      "options": {"temperature": 0.0, "num_predict": 100},
  }
  ```

  `"think": False` suppresses qwen3's thinking block at the source;
  `temperature 0.0` follows the assignment's guidance for small models.
- **REQ-24 (MUST)** Response handling, in order:
  1. if `response.status_code != 200` → return `[]`;
  2. `raw = response.json()["response"]`;
  3. defence in depth — strip any thinking block anyway:
     `text = re.sub(r"<think>.*?</think>", "", raw, flags=re.DOTALL)`;
  4. split on commas and newlines: `re.split(r"[,\n]", text)`;
  5. clean each part: strip whitespace, then strip the characters
     `-•*"'` and backtick from both ends, then strip whitespace again, then
     drop a single trailing `.`;
  6. drop empty parts, parts longer than 80 characters, case-insensitive
     duplicates (keep first occurrence), and any part equal to the whole
     question case-insensitively;
  7. return at most `MAX_KEYWORDS` items, original order preserved.
- **REQ-25 (MUST)** `expand_query` **never raises**. The whole network/parse
  body is wrapped in `try/except Exception: return []`. A timeout, connection
  error, non-JSON body, missing `response` key or empty parse all yield `[]` —
  the caller then searches with the raw query only. This is the assignment's
  mandatory fallback path.

### 4.4 `src/rag/fts.py` — BM25 full-text search

- **REQ-26 (MUST)** Tokenizer, verbatim (proven: Russian Snowball stemming
  makes «миграции» match «миграций»; Latin terms like `asyncpg`, `Ruff`, `FSD`
  pass through lowercased and unstemmed):

  ```python
  import re

  import snowballstemmer
  from rank_bm25 import BM25Okapi

  _stemmer = snowballstemmer.stemmer("russian")


  def tokenize(text: str) -> list[str]:
      """Lowercase, split on word characters, stem Russian word forms."""
      return _stemmer.stemWords(re.findall(r"\w+", text.lower()))
  ```

- **REQ-27 (MUST)** One public class:

  ```python
  class BM25Index:
      def __init__(self, chunks: list[dict]) -> None: ...
      def search(self, query: str, top_n: int) -> list[int]: ...
  ```

  `__init__` tokenizes `chunk["text"]` for every chunk and builds a
  `BM25Okapi` over the token lists; with an empty `chunks` list it builds
  nothing (guard — `BM25Okapi([])` divides by zero).
  `search` returns **chunk indices** (positions in the `chunks` list passed to
  `__init__`), best first: score every chunk with `get_scores(tokenize(query))`,
  keep only strictly positive scores, order by
  `sorted(range(len(scores)), key=lambda i: (-scores[i], i))` (deterministic
  tie-break by index), truncate to `top_n`. Empty index, empty query or no
  positive score → `[]`. Never raises.

### 4.5 `src/rag/fusion.py` — Reciprocal Rank Fusion

- **REQ-28 (MUST)** The whole module is exactly this proven fence (plus a
  module docstring). The formula is the assignment's
  `RRF_Score(d) = Σ 1/(k + r_m(d))` with 1-based ranks; ties break by
  ascending doc id for determinism:

  ```python
  def rrf(rankings: list[list[int]], k: int = 60) -> list[int]:
      """Fuse ranked doc-id lists via Reciprocal Rank Fusion."""
      scores: dict[int, float] = {}
      for ranking in rankings:
          for rank, doc_id in enumerate(ranking, start=1):
              scores[doc_id] = scores.get(doc_id, 0.0) + 1.0 / (k + rank)
      return sorted(scores, key=lambda d: (-scores[d], d))
  ```

  Proven values: `rrf([[1, 2, 3], [3, 1, 4]]) == [1, 3, 2, 4]`.

- **REQ-32 (MUST)** Two internal ranking helpers, both returning
  `list[int]` chunk indices, best first:

  ```python
  def _vector_ranking(query: str, top_n: int) -> list[int]:
      q_emb = _get_model().encode([query])
      faiss.normalize_L2(q_emb)
      _scores, ids = index.search(q_emb, top_n)
      return [int(i) for i in ids[0] if i != -1]


  def _fts_ranking(query: str, keywords: list[str], top_n: int) -> list[int]:
      if bm25 is None:
          return []
      return bm25.search(" ".join([query, *keywords]), top_n)
  ```

  The `i != -1` filter matters: FAISS pads with `-1` when the index holds
  fewer vectors than `top_n`.
- **REQ-33 (MUST)** Replace `retrieve` with:

  ```python
  def retrieve(query: str, mode: str = "hybrid"):
      """Retrieve relevant chunks; mode is "hybrid" or "vector"."""
      if index is None or len(chunks) == 0:
          if not _ensure_index_exists():
              return []
      if mode == "vector":
          return [chunks[i] for i in _vector_ranking(query, TOP_K)]
      keywords = expand_query(query)
      with ThreadPoolExecutor(max_workers=2) as pool:
          vec_future = pool.submit(_vector_ranking, query, CANDIDATE_POOL)
          fts_future = pool.submit(_fts_ranking, query, keywords, CANDIDATE_POOL)
          vec_ids = vec_future.result()
          fts_ids = fts_future.result()
      fused = rrf([vec_ids, fts_ids], k=RRF_K)
      return [chunks[i] for i in fused[:TOP_K]]
  ```

  This is the assignment's architecture verbatim: expansion first, then vector
  and full-text search **in parallel** (both futures are submitted before
  either result is awaited), then RRF, then top-K. The default keeps the
  upstream call sites (`assistant.py`, `ask`) on hybrid retrieval unchanged.
- **REQ-34 (MUST)** Harden `ask_llm` minimally: pass
  `timeout=LLM_TIMEOUT` to `requests.post`, add `"think": False` to its JSON
  payload, and apply the same `<think>` strip as REQ-24 step 3 to the returned
  text before returning it. Import `LLM_TIMEOUT` from `config`. Do not change

  runs against the same index may still differ slightly if the LLM changes

## 10. Non-goals

- **NON-GOAL** Migrating chunk storage to SQLite/FTS5. `rank_bm25` is the
  assignment-sanctioned in-memory option; with ~300 chunks a disk-backed FTS
  engine buys nothing. Storage stays FAISS + pickle as upstream.
- **NON-GOAL** An asyncio rewrite. The upstream codebase is synchronous;
  `ThreadPoolExecutor` (explicitly allowed by the assignment) delivers the
  required parallelism without touching call sites.
- **NON-GOAL** Rerankers, GraphRAG, multi-hop retrieval, conversation memory.
- **NON-GOAL** Swapping `all-MiniLM-L6-v2` for a multilingual embedding model.
  It would lift vector recall on the Russian corpus, but the assignment
  grades the hybrid mechanics; the weak vector baseline is part of the
  before/after story.
- **NON-GOAL** Any change to `src/mcp/`, `src/assistant.py`, `src/rag/embed.py`
  or `src/rag/chunk.py` (REQ-17). No new MCP tools.
- **NON-GOAL** Answer-quality (generation) evaluation. The benchmark measures
  retrieval only — deterministic and LLM-judge-free by design.
- **NON-GOAL** Filtering credentials out of retrieval results. The corpus is
  the operator's own private data and the assistant is a local CLI; secrecy is
  enforced at the repository boundary (REQ-09, `.gitignore`), not inside the
  retrieval pipeline.
- **NON-GOAL** CI workflows, Docker, packaging, publishing, type-checking
  gates, coverage thresholds, structured logging, metrics, Windows support.
- **NON-GOAL** Localization. All code, comments, tests, docs and log lines are
  English; only the bench fixture questions and corpus data are Russian.
